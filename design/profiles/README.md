# 애널 프로필 재검증 기록

`2026-10-calibrated.json`은 `lib/profiles.ts`·`lib/guideline.md`의 애널 표를 만든 원본이다.

- 관찰: 애널마다 리포트 최대 8건(최근 3·초기 2·6개월 성과 최고·최저·중간), 총 121건을 배치로 읽어 작성 습관을 기록 (`/api/profiles/job`, Blob `profiles/v1/obs/*`)
- 1차 제안 뒤 보정: KIRS 공통 문체(`houseStyle`)를 기준선으로 빼고 16명을 함께 놓고 유형·스탠스를 다시 배정
- 반영할 때 공통 문체를 되풀이하는 읽기 신호는 뺐고(65개 중 46개 유지), 관찰 6건 미만(정수현·이희경)은 관찰 프로필로 둠
- 프로필에는 성과 숫자를 넣지 않는다. 성과는 분석 때 발간일 기준 데이터로 따로 붙는다 (`lib/analysis-context.ts`)
